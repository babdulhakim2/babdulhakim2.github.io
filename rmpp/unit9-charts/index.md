# e-Portfolio Activity: Charts Example Worksheet

## Overview
This activity focuses on developing effective data visualization skills, exploring various chart types, and understanding principles of visual communication for research and professional contexts.

## Learning Objectives
By completing this activity, I will:
- Select appropriate visualization methods for different data types
- Create clear, informative charts and graphs
- Apply design principles for effective visual communication
- Critique and improve existing visualizations
- Understand accessibility considerations in data visualization

## Chart Types and Applications

### 1. Bar Charts and Column Charts
- **Use case**: Comparing categories or showing changes over time
- **Best practices**: Clear labeling, appropriate scaling, meaningful ordering
- **Example**: Survey response frequencies, performance comparisons

### 2. Line Charts
- **Use case**: Showing trends and changes over continuous periods
- **Best practices**: Consistent intervals, clear trend lines, appropriate axis ranges
- **Example**: Performance metrics over time, experimental measurements

### 3. Scatter Plots
- **Use case**: Examining relationships between two continuous variables
- **Best practices**: Meaningful axis labels, appropriate scaling, trend lines when relevant
- **Example**: Correlation analysis, regression visualization

### 4. Pie Charts and Alternatives
- **Use case**: Showing parts of a whole (limited use cases)
- **Best practices**: Limited categories, clear percentages, consider alternatives
- **Alternative**: Horizontal bar charts for better readability

### 5. Box Plots and Distribution Plots
- **Use case**: Showing data distribution and outliers
- **Best practices**: Clear quartile representation, outlier identification
- **Example**: Statistical analysis results, data quality assessment

## Design Principles
1. **Clarity**: Information should be immediately understandable
2. **Accuracy**: Visual representation should match the data
3. **Efficiency**: Minimize cognitive load for viewers
4. **Aesthetics**: Professional appearance without sacrificing function
5. **Accessibility**: Consider color-blind users and other accessibility needs

- **Tableau**: Advanced interactive visualizations
- **R/ggplot2**: Statistical graphics and customization
- **Python/Matplotlib/Seaborn**: Programmatic visualization
- **D3.js**: Web-based interactive visualizations
