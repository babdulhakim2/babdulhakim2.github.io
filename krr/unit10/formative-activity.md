# Unit 10 Formative Activity

## Task
Read section 4.1.2 onwards of Debellis, M. (2021) A Practical Guide to Building OWL Ontologies Using Protégé 5.5 and Plugins. Work through exercises 22-26.

## Exercise Progress

**Exercise 22:** Adding complex class definitions with restrictions

**Exercise 23:** Working with property chains and transitivity

**Exercise 24:** Implementing cardinality constraints

**Exercise 25:** Using the reasoner for consistency checking

**Exercise 26:** Query answering with DL queries

## Key Insights
The exercises demonstrated how reasoning adds intelligence to ontologies. Exercise 25's consistency checking caught logical errors I wouldn't have spotted manually. The DL query capabilities in Exercise 26 showed the power of combining formal logic with practical tools.
